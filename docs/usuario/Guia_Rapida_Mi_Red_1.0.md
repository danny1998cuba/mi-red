# Mi Red — Guía rápida

**Tu referencia diaria para clientes, cobros y respaldos · v1.0**

## Empieza en cinco minutos

1. **Ajustes → Mi negocio:** escribe nombre, moneda (solo etiqueta, no conversión) y prefijo si lo utilizas.
2. **Clientes → Añadir:** introduce nombre y mensualidad. Teléfono, dirección y notas son opcionales.
3. En la ficha del cliente, agrega antena, ONT o router con MAC y/o IP si las conoces.
4. **Cobros:** revisa el mes abierto y registra los pagos completos.
5. **Ajustes → Copias de seguridad:** crea una copia cifrada y guárdala fuera del teléfono.

## El ciclo mensual en 20 segundos

| Momento | Qué ocurre |
|---|---|
| **Día 30 del mes anterior** | Se abre la mensualidad del siguiente mes; si no existe día 30, último día. |
| **Días 1 y 2** | Los cargos sin pago válido aparecen como pendientes. |
| **Desde el día 3** | Los cargos aún impagados quedan como candidatos a suspensión. |

**La app NO suspende automáticamente el internet.** Un cliente activo puede tener deudas y uno suspendido puede haber pagado.

## Las cinco acciones más habituales

| Necesito… | Ruta rápida |
|---|---|
| Añadir un cliente | **Inicio → Añadir cliente** o **Clientes → Añadir** |
| Registrar un pago | **Cobros → Cliente → Registrar pago** |
| Consultar una deuda anterior | **Clientes → Ficha → Cobros e historial** |
| Enviar recordatorio | **Historial → Mensualidad impagada → Recordar por WhatsApp** |
| Compartir listado | **Cobros → Compartir listado → Vista previa → Compartir** |

**WhatsApp:** usa número internacional con `+` y código del país. El texto se abre para que **tú** decidas enviarlo; Mi Red no lo envía sola.

## Regla de oro del respaldo

**Ajustes → Copias de seguridad → Crear copia → Contraseña → Elegir destino.**

- Archivo: `.miredbk`, cifrado y protegido con contraseña de **12 caracteres como mínimo**.
- Guarda el archivo fuera de Mi Red y **otra copia fuera del teléfono**.
- Guarda la contraseña aparte. **Si la olvidas, no se puede recuperar la copia.**
- Restaurar: **Ajustes → Copias de seguridad → Restaurar copia**. Revisa la vista previa: **reemplaza TODOS los datos**.

## Antes de actualizar o cambiar de teléfono

**Haz una copia, comprueba que existe y recuerda su contraseña.** Instala las actualizaciones firmadas por el mismo desarrollador sobre la app existente. No desinstales primero, porque podrías perder la base local.

## Si algo no cuadra

- Pago reciente, deuda aún visible → revisa meses anteriores en el historial.
- Notificación que no llegó → verifica permiso/ahorro de batería; abre la app para ver el estado real.
- Cambiaste la moneda → los importes **no se convierten**.
- Número WhatsApp incorrecto → corrige el número internacional antes de abrir el enlace.
